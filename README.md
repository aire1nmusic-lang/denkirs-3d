# denkirs-3d — 3D-модели и фотометрия DENKIRS для конфигуратора треков

База для 3D-редактора на denkirs.ru/configurator (Б24 87590).

- Модели: `https://docs.denkirs.ru/3d/Denkirs/<артикул>.rar|zip` (OBJ, а если его нет — FBX/3DS/DAE через assimp) → `m/<БАЗА>.dkm` (≈2,5 тыс. треугольников, ~20 КБ) + `m/index.json` (источник, габарит в мм, заметки чистки).
- Чистка: лишний кусок трека и соседние варианты светильника из архива убираются автоматически (`note` в index.json).
- Фотометрия: `https://docs.denkirs.ru/ies/Denkirs/` → `ies/<БАЗА>.ies` + `ies/index.json` — для расчёта освещённости по паспорту.
- Сайт берёт файлы через CDN: `https://cdn.jsdelivr.net/gh/aire1nmusic-lang/denkirs-3d@main/m/index.json`.
- Репозиторий **публичный**: только то, что и так открыто на docs.denkirs.ru. Ключей, паролей и токенов сюда не класть.

## Как обновить
Actions → «Обновить 3D-модели» → Run workflow. Раз в месяц запускается сам. Список артикулов — `lamps.txt`. Нет модели — конфигуратор рисует светильник по габаритам из каталога.

## Формат .dkm v1
`Float32[8]` nV, nI, min xyz, max xyz (мм, Y вверх) → `Int16[nV·3]` позиции в габарите → выравнивание до 4 байт → `Uint16|Uint32[nI]` индексы.

Владелец: отдел совершенствования (Андрей Литвинов). Код — `scripts/convert.mjs`.
